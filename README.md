## 홈페이지 소개

교회 소개, 예배 시간, 가정예배 순서지, 오시는 길을 한 페이지에서 확인할 수 있는 반응형 정적 홈페이지입니다. PC와 모바일 환경을 지원하며, 가정예배 순서지는 웹 미리보기와 PDF 다운로드를 제공합니다.

별도의 서버나 데이터베이스 없이 HTML, CSS, JavaScript로 구성되어 있으며 `main` 브랜치에 변경 사항이 올라오면 GitHub Actions를 통해 GitHub Pages에 자동 배포됩니다.

```text
index.html       홈페이지 내용
styles.css       디자인과 반응형 레이아웃
script.js        모바일 메뉴, 순서지 탐색과 미리보기
bulletin-builder/ 교회 주보 제작 도구
assets/          로고, 사진, 글꼴, 가정예배 순서지
scripts/         배포 전 파일 및 링크 검사
```

로컬에서 확인하려면 저장소 루트에서 다음 명령을 실행하고 `http://localhost:8000`에 접속합니다.

```sh
python3 -m http.server 8000
```

배포 전 파일과 내부 링크는 다음 명령으로 검사할 수 있습니다.

```sh
python3 scripts/check_site.py
```

교회 로고, 사진, 주보를 포함한 콘텐츠의 저작권은 큰소망교회에 있습니다.
